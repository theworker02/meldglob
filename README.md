# meldglob

Meld digests and glob fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/meldglob/

## Install / run

```bash
git clone https://github.com/theworker02/meldglob.git
cd meldglob
node src/cli.js
node --test
```
